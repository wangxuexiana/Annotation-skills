- 核心任务：针对同一 user prompt 和同一参考图，分别检查候选模型产物的视觉还原质量、功能交互和动效实现，并对每个产物打分。

## 核心判定

- 有 UP 指令时：如果指令中存在页面布局修改内容，最终还原效果按 UP 指令描述后的布局为准。
- 无 UP 指令时：按参考图判定还原度，整体还原太差直接 0 分。
- 先判断废弃/不可比情况，再做 0/1/2 分判定。
- 2 分只能从已经达到 1 分的产物中晋升，多个 1 分产物中只能选一个最佳产物为 2 分，不能直接给 2 分。

## 分值定义

- 2 分：最佳产物。存在多个完美或近乎完美的 1 分产物时，选择其中最优的一个晋升为 2 分。
- 1 分：完整复刻。页面整体布局、结构、主要元素、视觉层级与参考图高度一致，并且 prompt 中的功能交互也完全实现；整体复刻效果约 95% 以上。允许字体、图标、按钮有少量差异；裂图通常不允许，除非占比特别小；非核心交互或动效可在美观度达标时忽略。
- 0 分：还原度差。大部分内容未还原，或 prompt 中功能交互未实现，或白屏、严重错位、核心内容缺失。0 分需要上传问题局部截图，可以加标注文字。

## 操作流程

- 进入领题页，打开对应 VLM Coding 还原度任务。
- 做题页通常包含 UP 指令、参考图、模型切换、产物查看和打分原因区域。
- 对每个候选产物逐一检查参考图、UP 指令和可见页面效果。
- 必要时测试 prompt 明确要求的点击、切换、布局调整、样式调整等交互。
- 0 分产物上传对应问题截图。
- 多模型产物中如存在 1 分，需要最终选一个最佳 1 分晋升为 2 分。

## 易错点

- 不要把参考图中的 hover、弹窗、选中、展开等静态视觉状态自动扩展成功能评测，除非 UP 明确要求真实交互。
- 额外交互不能破坏布局、颜色、内容或状态还原。
- 裂图一般不能给 1 分，除非非常小且不影响核心区域。
- 白屏、严重错位、核心内容缺失直接 0 分。
- 大部分结构与功能未实现直接 0 分。
- 近乎完美但存在小瑕疵可以给 1 分。
- 只看美观度不够，必须同时检查布局、元素、内容、视觉、幻觉和 UP 功能。

## 理由话术

- 原因要短、具体、自然中文，直接指出决定分值的主要差异。
- 0 分原因要覆盖关键缺陷，例如图片缺失、布局位置错误、核心卡片或导航差异、颜色背景不符合、功能点击无效。
- 1 分原因可写主要小瑕疵并说明整体还原到位，例如“商品图片存在差异其他整体按照参考图完全实现”。

## 问卷知识点

- 2 分只能由 1 分晋升，且只能选一个最佳产物。
- 有 UP 指令时按指令修改后的目标布局判定。
- 无 UP 指令时按参考图判定。
- 0 分需要上传问题截图。
- 非核心动效未实现但整体美观和还原达标时可给 1 分。
- prompt 与参考图不对应但产物按 prompt 生成属于废弃案例。
