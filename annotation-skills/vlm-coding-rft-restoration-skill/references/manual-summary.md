# VLM Coding RFT 还原度 Manual Summary

## 官方任务定义

针对同一 user prompt、同一参考图，对候选模型产物进行视觉还原质量与功能/动效实现评估，并给每个产物打分。

## 评分标准

| 分值 | 判定 |
| --- | --- |
| 2 | 最佳产物。多个 1 分中选择一个最优产物晋升为 2 分。 |
| 1 | 完整复刻。整体布局、结构、主要元素、视觉层级与参考图高度一致，prompt 中功能交互完全实现，整体复刻约 95% 以上。 |
| 0 | 还原度差。大部分内容未还原，prompt 功能交互未实现，或白屏、严重错位、核心内容缺失。 |

## 题目判断

- 有 UP 指令：如果指令里存在页面布局修改内容，最终还原效果以指令描述后的布局为准。
- 无 UP 指令：按参考图判定还原度，效果太差直接 0 分。

## 维度判定

### 还原度

- 布局与空间关系：整体版式、位置、尺寸比例、对齐、间距、首屏可见内容是否接近参考图。
- 元素完整性：核心区块、导航、卡片、按钮、图标、图片、图表、背景装饰是否完整。
- 内容准确性：清晰可读文字、数字、标签、按钮文案、价格、日期、图表语义是否准确。
- 视觉还原度：颜色、字体、字号、字重、圆角、阴影、边框、背景、纹理、留白、层级是否接近。
- 幻觉控制：是否新增参考图没有的大模块、广告、弹窗、导航、图片或无关文案。

### 功能交互

- UP 功能完整性：UP 要求的点击、切换、布局调整、样式调整等是否覆盖。
- 不破坏还原：额外交互不能导致布局、颜色、内容、状态偏离参考图。
- 不滥用交互：参考图展示 hover、弹窗、选中、展开等状态时，如果 UP 没要求真实交互，只按视觉状态还原评价，不自动扩展成功能评测。

## 分值选择细则

- 完美符合先给 1 分；多模型产物里如果存在 1 分，需要从 1 分中选择一个最佳产物打 2 分。
- 白屏、严重错位、核心内容缺失的产物记 0 分。
- 允许字体、图标、按钮少量差异。
- 裂图一般不允许，除非占比特别小。
- 少部分布局变化且一眼看不出差异点，可以评 1 分。
- 美观度达标时，非核心动效未实现仍可给 1 分。
- 产物近乎完美但有小瑕疵可以评 1 分。
- 大部分结构与功能未实现评 0 分。
- 0 分需要上传对应问题截图，允许截图中加标注文字。
- 2 分只能通过 1 分晋升，不能直接评 2 分。

## 废弃案例

- prompt 需求与参考图对应不上，但是实际产物是按照 prompt 进行生成。

## 示例中的判定倾向

- 首页图片缺失、关键分区样式布局不符、背景颜色未还原，可判 0 分。
- 顶部导航位置错误、首页布局元素不一致、关键交互点击效果或日期点击不可用，可判 0 分。
- logo、数据图表、顶部卡片图标存在差异，即使整体还原接近，也可能判 0 分。
- 顶部导航、中间图文对齐方式、底部背景配色不符合，可判 0 分。
- 整体还原度高但首页文字对齐、世界观背景、下方背景颜色有差异，示例仍判 0 分，说明该队列对明显视觉偏差较严格。
- 商品图片有差异但其它整体完全按参考图实现，可判 1 分。
