# User Style

Use this file as the first source for reason wording when the user provides historical annotation answers.

## Active Constraints

- Reasons should be compact and colloquial.
- Prefer concrete visible evidence over abstract praise.
- Use Chinese commas for clause breaks when multiple clauses are needed.
- Avoid slashes, colons, semicolons, parentheses, and final full stops in submitted reasons unless the queue explicitly requires them.
- Most reasons should be one sentence.
