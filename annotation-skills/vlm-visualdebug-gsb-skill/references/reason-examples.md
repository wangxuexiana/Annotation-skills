# Reason Examples

Use these as phrase pools only. Adapt them to the current visible evidence.

- A 胜出，A 目标问题修复更完整，B 虽然有改动但核心错位仍然明显
- B 胜出，B 把输入框背景色问题进行啦修复，A 只修了导航栏高度，核心视觉差异还在
- A 胜出，两侧都修复了目标问题，但 A 的页面还原度更接近参考图，B 的内容区域有明显挤压
- B 胜出，A 和 B 都能走通核心功能，但 B 的表单提交验证和状态反馈更完整
- A same B，两侧都没有修好目标问题，失败程度接近，没有一侧明显更好
- A same B，两侧都修好了目标问题，剩下差异很小，不影响核心判断

## Evidence Patterns

- Target repair: A 修好了题目指出的导航栏高度问题，B 仍有明显偏差
- Restoration: B 的模块层级和参考图更接近，A 的比例和间距偏差更明显
- Functional completion: A 的按钮点击后有正确反馈，B 只展示了静态页面
- Side effect: B 虽然修了目标问题，但把下方内容挤压变形，副作用更明显
- Equal quality: 两侧核心问题和副作用都接近，差异不足以拉开质量
