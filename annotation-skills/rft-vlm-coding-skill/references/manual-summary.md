# Manual Summary

## 适用范围

本摘要只覆盖 `RFT人标支持VLM Coding 还原度` 及其含 video 判断的派生队列。原文同一 Wiki 中还包含美观度、素材筛选、录屏质量等其它队列规则，做本队列时不要混用。

## 官方规则摘录后的操作化理解

- 标注目标：判断模型页面复刻和交互动效是否实现，判断模型是否按照 Prompt 描述生成页面。
- 输入材料：参考图、Prompt、多个模型产物。
- 核心维度：
  - 图片还原度：整体布局、结构、主要元素、视觉层级与参考图是否高度一致。
  - 功能满足度：Prompt 中明确提及的功能是否实现，交互是否正常，结果是否正确。
- 评分：
  - 0 分：还原度差，大部分内容没有还原实现，Prompt 功能交互没有实现；或页面报错、白屏、黑屏、无法交互。
  - 1 分：完美符合或基本完全符合，允许小瑕疵；页面整体布局、结构、主要元素、视觉层级与参考图高度一致，Prompt 功能交互也都实现。
  - 2 分：最佳产物，只能从 1 分晋升，不可直接给；不是必须存在。

## 最新优先规则

- `RFT人标支持VLM Coding（bon7数据）` 新增规则优先：
  - 所有模型全部是 0 分时，不需要选最好。
  - 只要所有模型不全是 0 分，就必须有且仅有一个 2 分模型产物。
- 这条会改变早期“2 分不是必须”的宽松表述：在 bon7 当前队列中，非全 0 时必须选唯一最佳 2 分。

## 标签与原因

- 0 分、1 分必须勾选问题类型：
  - 视觉不足：静态页面复刻、布局、结构、视觉层级等问题。
  - 功能不足：用户输入中明确要求的功能、动效、交互没有实现或表现错误。
- 0/1 分原因要简写，不要展开所有细节，只写核心错误和最终得分依据。

## 图片资源规则

- 参考网页中的图片内容和实际渲染图片内容不一致时，通常可忽略，只要不是坏图。
- 例外：题目提供了可用静态资源，或工具支持搜图/生图时，应按资源要求判断。
- 坏掉的图片链接不能豁免，不能给 2 分。

## 含 video 判断队列

- 只适用于队列 ID `7630729558178434842`。
- video 评分是动效/交互丰富度评分。
- 只有功能和还原度达到满分后才触发 video 评分。
- 评分：
  - 0：完全没有跳转，或完全没有动画效果。
  - 1：有一些简单跳转，或简单动画效果。
  - 2：有明显跳转，或静态截图无法展示完整网站信息。

## 后续批次差异

- 只有参考图、没有 Prompt：不看功能，只看还原度；如果该批次要求 video，则再评 video。
- 有 Prompt 和参考图：按正常规则看还原度与 Prompt 功能。
- 有些指定队列不需要评 video，应以当前队列说明为准。
