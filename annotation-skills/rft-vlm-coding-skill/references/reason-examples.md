# Reason Examples

Use these as phrase pools, not fixed templates.

- 视觉不足：整体布局和参考图差异较大，关键模块位置不一致。
- 视觉不足：主体结构基本对，但间距和层级还原不够准确。
- 功能不足：Prompt 要求的悬浮变亮效果未实现。
- 功能不足：按钮点击后没有明显反馈，核心交互不完整。
- 二者都有：页面结构还原不足，且核心交互没有响应。
- 1 分：主体结构和功能基本符合，但部分样式细节与参考图有偏差。
- 2 分：整体还原度最高，Prompt 要求的交互也能正常触发。
- 0 分：页面主体方向和参考图不一致，核心内容缺失。
