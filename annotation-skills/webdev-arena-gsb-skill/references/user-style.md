# User Style

Use this file for reason wording in WebDev Arena GSB annotation.

## Active Style For This Queue

- Reasons should be detailed enough for attribution analysis, usually one compact paragraph rather than a very short phrase.
- Reasons must follow the manual's recommended writing template: label conclusion, stronger side's concrete advantages, weaker side's concrete problems, key gap, and how that gap maps back to the prompt requirements.
- Start from the chosen label when useful, then explain the stronger side, the weaker side, and the key gap.
- Mention both model one and model two when evidence is available.
- Prefer concrete visible evidence: layout, spacing, color, typography, content, material use, interaction, loading state, and prompt-following details.
- Avoid English words that non-specialist annotators may not recognize; use natural Chinese replacements where possible, and keep necessary prompt terms only when they are central to the task.
- Do not use quotation marks in submitted reasons, including Chinese corner quotes, straight quotes, or curly quotes; rewrite quoted prompt wording as plain Chinese prose.
- Avoid piling up specific numbers from the prompt in the reason, such as exact pixel sizes, counts, or repeated measurements. Mention a number only when that number itself is the key difference between the two models.
- It is acceptable to use normal Chinese punctuation in this queue because the manual asks for detailed evaluation.
- Avoid empty praise unless followed by concrete evidence.
- Avoid overly formal audit wording; write like a human annotator explaining the decision.
- Do not submit a reason that only lists scattered observations; reshape it into the manual template before filling the form.
- For abandoned or waste items, keep the reason brief. Only state the broad reason for abandonment, such as both products cannot display, requested output form does not match, or required reference information is missing; do not write a full GSB-style comparison or list many detailed feature checks.
