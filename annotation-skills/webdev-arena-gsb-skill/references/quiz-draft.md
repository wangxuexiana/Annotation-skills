# Quiz Draft

当前没有实际问卷题目。以下是根据手册和录屏整理的可能考点，用于权限问卷草稿。

## 可能考点

1. G/S/B 含义
   - 答案：G 是模型一明显更好，S 是两者相当或同样好/同样差，B 是模型一明显更差也就是模型二更好。
   - 证据：手册 2.1 与录屏 GSB 讲解。
   - 置信度：高。

2. 两个产物都无法加载怎么办
   - 答案：废弃。
   - 证据：手册 2.2 题目判断。
   - 置信度：高。

3. 只有一个产物无法加载怎么办
   - 答案：正常作业，不废弃，比较并说明无法加载的一方问题。
   - 证据：手册 2.2 与录屏题目判断。
   - 置信度：高。

4. 是否只看最后一轮 prompt 或中文摘要
   - 答案：不能，只能作为辅助，必须阅读完整多轮用户消息并结合摘要理解完整需求。
   - 证据：手册「标注前先看什么」与录屏强调摘要可能遗漏细节。
   - 置信度：高。

5. 网页复刻题参考图不完整时怎么判
   - 答案：按完整网页要求评估，不能只按参考图首屏判断。
   - 证据：手册 2.2 与录屏网页复刻说明。
   - 置信度：高。
