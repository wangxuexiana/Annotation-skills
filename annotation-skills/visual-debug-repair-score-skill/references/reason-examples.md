# Reason Examples

Use these as phrase pools. Adapt to the current visible evidence.

- 0 分：核心问题没有修好，修复后仍能看到原问题
- 0 分：页面一直加载，无法正常查看修复效果
- 1 分：问题已修复，但布局和参考图差异明显
- 1 分：修复方向对，但样式和内容还原度不高
- 1 分：主问题修好了，但 UP 指令没有完全实现
- 2 分：问题修复完成，页面结构和参考图高度一致
- 废弃：修复前产物没有题目描述的问题，题目本身不成立
- 废弃：参考图异常，无法按正常标准判断
- 多候选：同题只能保留最佳 2 分，其他候选降为 1 分
