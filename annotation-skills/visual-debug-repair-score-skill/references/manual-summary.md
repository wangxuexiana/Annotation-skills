# Visual Debug 修复评分手册摘要

## 适用范围

本手册适用于 Visual Debug 新工艺相关题目，用于判断模型是否按照 Prompt 中的问题描述完成视觉问题修复，以及修复后的网页产物是否与参考图保持足够高的一致性。

## 标注流程

1. 查看图片产物和问题修复描述。
   - 确认参考图页面结构、主要视觉元素和最终目标效果。
   - 明确题目要求修复的具体问题。
2. 查看网页产物并初判。
   - 打开修复后的网页产物。
   - 从首屏浏览到页面底部。
   - 检查问题是否已修复，整体布局、主要模块、文本信息、视觉风格是否与参考图一致。
   - 页面一直加载或无法正常展示时直接评 0 分。
3. 命中废弃规则时直接废弃，不进入 0/1/2 分。
4. 处理 2 分候选唯一判定。
   - 同一题出现多个可评 2 分的网页产物时，继续比较修复程度和页面还原度。
   - 只保留最好的一个产物为 2 分，其余统一降为 1 分。

## 评分标准

| 分值 | 判定标准 | 操作说明 |
|-|-|-|
| 0 分 | 问题没有修好；或网页产物加载不出来、一直处于加载状态。 | 核心问题仍然存在，或页面无法正常查看，直接 0 分。 |
| 1 分 | 问题已经修复，但与原图相似度不高，仍存在明显视觉差异。 | 适用于“修好了，但还原不够像”。 |
| 2 分 | 问题修复完成，且与参考图还原度高，需要看对应 UP 指令是否完全实现。 | 修复效果和视觉还原都达标，才可进入 2 分候选。 |

## 废弃规则

- 问题描述的错误原因，修复前产物没有这个问题，直接废弃。
- 题目本身有明显问题时废弃，例如 Prompt 与参考图不对应、参考图异常、截图顺序错误或信息缺失。
- 参考图有问题，且修复需要按照有问题的参考图进行时废弃。
- 非文字题目中，Prompt 没有问题描述，也没有参考图时废弃。

## 评分示例抽象

- 问题仍未修复，或页面无法正常加载：0 分。
- 问题已修复，但布局、样式或内容与参考图仍有明显差异：1 分。
- 问题修复完成，页面结构、视觉效果与参考图高度一致，并且指令完全一致：2 分。
- 同一题多个高质量候选：1 个 2 分，其余 1 分。
- 题目命中废弃规则：废弃。

## 终审要点

- 先确认是否废弃，再正常评分。
- 确认分值同时符合问题修复情况、网页还原度和 2 分唯一判定规则。
- 2 分不能同时给多个产物。
