## Likely Quiz Answers From The Manual

- The first priority is whether the current reported problem is repaired.
- Rubric `无法判断` is only for insufficient evidence, not for confirmed candidate failure.
- A/B overall scores are not the simple average of rubric pass rate.
- Use Same/Tie only when A and B are substantively close.
- Returned tasks require rechecking rubrics, scores, preference, and reason.
- Waste is only for tasks that truly cannot be judged, such as missing key input or both A/B links inaccessible.
