# User Style

No historical answers were provided for this queue yet. Until user examples exist, follow this default style.

## Active Style Constraints

- Use natural Chinese annotation wording.
- Keep rubric reasons short, usually one clause or one sentence.
- Dimension reasons can be more detailed, especially for non-full scores.
- Pairwise reasons should name the decisive difference between image1 and image2.
- Pairwise reasons should be concise: include 2-3 key concrete differences between image1/image2 and GT when needed, but do not write a long exhaustive comparison.
- Reasons should only state the visible reason itself. Do not add scoring conclusions such as "所以 O2/O3 给几分", and do not add dimension-routing explanations such as "其他有问题，属于 O2/O3".
- Avoid empty phrases such as“更准确”“不准确”“有问题”without the visible component.
- Prefer concrete chart components: 图表类型、散点层、误差棒、坐标轴量程、主刻度、图例、单位、色条、主峰、次峰、数据源说明、遮挡、留白、颜色、字体、线条粗细。
- Submitted reasons may use normal Chinese punctuation if the platform permits it. If the user later asks for comma-only style, treat that as a hard override.
