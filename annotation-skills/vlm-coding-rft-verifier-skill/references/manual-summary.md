# VLM Coding RFT Verifier Manual Summary

## 任务目标

- 每道题包含原图/GT、复刻图 image1、复刻图 image2、O1/O2/O3 初始 rubrics。
- 人工标注需要：
  - 检查并优化 O1/O2/O3 rubrics。
  - 对每条最终 rubric 分别给 image1 和 image2 打 0、0.5 或 1。
  - 给 image1 和 image2 分别打 O1/O2/O3 维度分并写维度理由。
  - 核对 overall 总分。
  - 判断 image1 胜出或 image2 胜出，并写 pairwise reason。

## 标注总流程

1. 先整体观察原图，判断图表类型、核心意图、坐标轴、图例、数据趋势和视觉布局。
2. 对照 image1、image2，分别检查两张复刻图与原图的差异。
3. 检查 O1/O2/O3 初始 rubrics 是否准确，必要时修改、删除或补充。
4. 对每条最终 rubric，分别给 image1 和 image2 打 0、0.5 或 1，并写一句理由。
5. 根据逐条 rubric 表现，给 image1 和 image2 分别打 O1/O2/O3 维度分，并写维度理由。
6. 根据 O1/O2/O3 维度分计算或核对 overall。
7. 根据总分和关键错误严重程度，选择 image1 胜出或 image2 胜出，并写 pairwise 理由。
8. 提交前检查漏填、分数不一致、理由过泛、需要 report 讨论的情况。

## O1/O2/O3 定义

### O1 图表类型与意图理解准确度

- 关注：图表主类型、特殊变体、多系列、多轴、层级结构、核心表达意图是否正确。
- 优先级：门槛维度。O1 失败时 overall 直接为 0。
- 维度分：0、2、4。
- 4 分：图表类型、变体和核心意图完全匹配。
- 2 分：核心意图正确但有瑕疵。
- 0 分：不能表现核心意图或图表类型严重错误。

### O2 核心元素准确度

- 关注：坐标轴、量程、数据点、趋势、图例、标题、单位、色条、统计量等是否准确。
- 优先级：最高权重。图表传递的数据是否正确主要看 O2。
- 维度分：0、1、2、3、4。
- 4 分：所有核心元素完美准确。
- 3 分：核心映射正确，仅次要元素有很小瑕疵。
- 2 分：存在非致命但明显的数据或上下文问题。
- 1 分：核心考点严重失败，导致错误数据信息。
- 0 分：数据映射完全错误或严重幻觉。

### O3 布局结构与视觉风格一致性

- 关注：布局、对齐、间距、遮挡、颜色、字体、网格线、背景风格是否接近原图。
- 维度分：0、1、2、3、4。
- 4 分：布局、对齐、视觉风格与原图完美一致。
- 3 分：仅有极微小对齐、锚点或颜色对比度差异，不影响整体。
- 2 分：明显遮挡、网格线错误、布局重排或配色线条突兀。
- 1 分：严重遮挡导致关键数据不可读、对比度极低或结构严重扭曲。
- 0 分：视觉结构完全崩坏。

## Rubrics 优化规则

- 初始 rubrics 是辅助材料，不是全集。
- 需要修改的情况：
  - 描述的图表元素与原图不一致。
  - 坐标轴范围、标题、颜色、关键点位置等写错。
  - 描述过模糊，无法实际判断。
  - 把次要视觉问题写成核心数据问题，或遗漏核心数据问题。
- 需要补充的情况：
  - 关键数据系列、坐标轴、色条、图例、统计量未覆盖。
  - 特殊结构未覆盖，如双轴、多子图、堆叠图、极坐标、热力图、地图、树图、雷达图等。
  - 明显影响解读的视觉结构未覆盖，如遮挡、裁切、颜色极性、文字可读性。
- 好 rubric 应该可观察、可判断，让另一个标注同学也能判断 0、0.5 或 1。

## 逐条 Rubric 打分

- 1：完美精准，复刻图完全符合该考点，与原图在该考点下基本无差别。
- 0.5：基本准确，大方向正确，但具体数值点、位置、文字、颜色或布局有轻微偏差，不改变主要结论。
- 0：严重错误，不满足该考点，或错误会影响主要信息判断，如趋势反转、量程错误、关键元素缺失。
- 理由必须引用可见事实，不能只写“准确”“不准确”“有点偏差”。

## Overall 总分

- 如果 O1 = 0，overall = 0。
- 如果 O1 >= 2，overall = 0.25 * O1 + 0.65 * O2 + 0.10 * O3。
- 若需要手填，保留两位小数。
- 若页面自动计算，也要核对是否符合选择的 O1/O2/O3 分数。

## Pairwise 胜负判断

- 选项只有 image1 胜出或 image2 胜出。
- 判断顺序：
  1. 先看 overall，高分通常胜出。
  2. 总分相同时，看 O2 和 O1 的主需错误严重程度。
  3. O1/O2 接近时，再看 O3 的布局和视觉风格。
  4. 总分和人工直觉不一致时，需要勾选 report 讨论并说明原因。
- Pairwise reason 要具体说明 image1 相比 image2 的优势或劣势。

## 图表类型专项规则

- 多系列与多轴结构：组合图的独立核心系列、双/多轴结构要完整复现。
- 层级饼/环/旭日图：同心层数和父子映射关系要复现。
- 坐标系与量程：轴端点、量程、递增方向、主刻度、单位/幂级要准确；端点/量程改写、正负互换、X/Y 互换、Z 轴反转为严重错误。
- 离散轴标签：标签语义、归属、关键区段解读要正确。
- 图例文本与注释：标题、单位、公式、图例、关键数值标签要准确。
- 系列-轴绑定：轴单位绑定、分组重叠度、高度与量程比例要正确。
- 颜色刻度与色条：端点、量程、主刻度、尺度类型、单位及极性要准确。
- 拓扑/等高线/热力/3D 曲面：峰/谷数量、热点等级、连通区边界、色彩极性要正确。
- 散点/点云与二维分箱：主峰/密度带分布、走向、旋转角度、质心偏移要正确。
- 地理坐标：经纬轴刻度、网格可读性、点位拓扑关系要正确。
- 折线/阶梯/时序趋势：趋势方向、关键峰谷位置、交叉关系要正确。
- 甘特/时间轴：端点/步长、全局平移、行合并/拆分要正确。
- 统计分布：误差棒范围和位置、Q1/Q3/中位数、离群点要正确。
- 堆叠图：跨组排序、成组数据完整性、单组高度和子段占比要正确。
- 参考线/统计量：文本与虚线位置、斜率和关键结论要正确。
- 极坐标/风玫瑰/雷达图：径向刻度、起始角、轴向、等角锚点要正确。
- 矩形树图：面积排序、Top10 偏离、密集区瓦片重排要正确。
- 层级图和 Waffle 图：父子层绑定、求和校验、总数和多类别计数要正确。

## 常见误判

- 只看哪张图更美观是错误的；先看类型和数据逻辑。
- 大体像原图不代表高分；必须查坐标轴、量程、数据点、图例、色条和关键文本。
- 初始 rubrics 错了必须先修。
- 次要视觉问题不要当致命错误，数据错误优先级高于轻微风格差异。
- 理由不要只写“更准确”，要说明具体准确在哪里。

## 返修题处理

- 若页面顶部有质检返修意见，先读返修意见，再检查对应部分。
- 返修时不要只改 pairwise reason，要同步检查 rubrics、逐条分数、维度分和 overall。
- 如果认为原标注没有问题，也要写清证据。

## 提交前自检

- 已查看原图、image1、image2。
- 已检查并优化 O1/O2/O3 rubrics。
- 每条最终 rubric 都已分别给 image1 和 image2 打 0、0.5 或 1。
- 每条 rubric 的 image1/image2 理由都已填写。
- image1/image2 的 O1/O2/O3 维度分和维度理由都已填写。
- overall 已计算或核对无误。
- pairwise 结果与总分和关键错误严重程度一致；如不一致，已 report 讨论并说明。
- pairwise reason 写清 image1 与 image2 的关键差异。

## 一句话标准

原图是唯一基准；O1 看类型和意图，O2 看数据和核心元素，O3 看布局和视觉。先保证图表“对”，再判断图表“像”。
