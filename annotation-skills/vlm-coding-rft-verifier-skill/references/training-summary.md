# VLM Coding RFT Verifier Training Summary

## 任务与队列

- 任务名称：VisualCoding Verifier / VLM Coding RFT 图表复刻人工标注。
- 当前材料来源：
  - 手册：`https://bytedance.larkoffice.com/docx/ZJhLdYJg3owtrDxnGhQcCm1Mnqb`
  - 录屏妙记：`https://bytedance.larkoffice.com/minutes/obcnbi3k391idyd87ao8643t`
- 标注形态：每题展示一张原图/GT 与两张模型复刻图 image1、image2。
- 标注目标：优化 O1/O2/O3 rubrics，对 image1 和 image2 分别逐条评分，再给两张图分别打 O1/O2/O3 维度分，核对 overall，并选择 pairwise 胜出图。
- 当前培训强调为第三期/端午队列，先开放约 1000 题双盲标注，后续长期有题。标注端单题约 30 元，质检队列另建，质检单题约 10 元。

## 核心判定

- 原图/GT 是唯一参考基准，所有判断必须基于原图、image1、image2 的可见事实。
- 先看图表类型与意图，再看数据和核心元素，最后看布局与视觉风格。
- O1、O2、O3 必须独立评价，不要把其他维度的问题提前扣到当前维度里。
- O1 看图表类型、特殊变体和高层意图。不要因为数值趋势错、标签重叠、颜色字体、布局遮挡而扣 O1，除非 O1 rubric 明确把该点写成意图要求。
- O2 看数据映射与核心元素准确度，包括数值、趋势、点位、比例、坐标轴量程、刻度、单位、标题、标签、图例、静态辅助元素的存在和可读性。
- O3 看空间布局与视觉风格，包括遮挡、裁剪、留白、模块位置、颜色、字体、线条粗细、点型、背景和整体比例。
- 数据与逻辑优先级高于美观。pairwise 先看 overall，再看 O2/O1 的关键错误，O1/O2 接近时再看 O3。
- O1=0 时 overall 按公式为 0，但录屏强调页面上 O1=0 后仍要继续评完所有 rubrics、O2/O3 维度分和理由。

## 操作流程

1. 整体观察原图，识别图表主类型、特殊变体、核心意图、坐标轴、图例、数据趋势和布局。
2. 对照 image1 和 image2，分别记录两张复刻图与原图的差异。
3. 先检查机器生成的 O1/O2/O3 rubrics 是否准确、完整、属于正确维度。
4. 若 rubric 不准，先修改或补充，再开始评分。修改完再打分，不要先打分后改 rubric。
5. 每条最终 rubric 都要分别给 image1 和 image2 打 0、0.5 或 1，并给出可见事实理由。
6. 再给 image1 和 image2 分别填写 O1/O2/O3 维度分和详细理由。
7. 核对 overall。若页面自动计算，也要确认是否符合公式。
8. 选择 image1 胜出或 image2 胜出。若总分和人工直觉不一致，需要 report 讨论并写清原因。
9. 提交前检查 rubrics、逐条分数、维度分、overall、pairwise 和理由是否一致。

## Rubrics 修改与补充要求

- 不要盲信机标 rubrics。录屏强调这是本批次质量重点。
- 遇到不合理、不准确、描述不够严格或遗漏关键差异点的 rubric，必须修改或新增。
- 培训中给出强约束：大约 10 题里至少应有 1 到 2 题需要修改或补充 rubrics。不要为了完成数量乱改，但确实不合理时必须改。
- 修改 rubric 是修缮当前维度下针对原图的标准，不是随意删掉再写无关内容。
- 如果机器 rubric 完全不准，可以依据当前维度的评价目标，重写成能观察、能判断的 rubric。
- 当 A/B 有明显差距，而当前 rubrics 没覆盖这个影响胜负的关键差异时，必须补充该维度下的 rubric。
- 例：房价热力图应严格描述不同热度区域范围、色块区域范围、主峰/次峰区域；数据源说明要写清位于图表框右下角且有淡黄色矩形外框。
- 例：误差棒不仅要看上下端点和短横线帽样式，还要补充误差棒位置是否介于对应柱体之间。

## 维度边界和易错点

- O1 只看图表类型与意图识别。示例：原图是雷达图加散点图，image 缺散点图，则 O1 不能给满，因为组合图类型/意图不完整。
- O1 可给高分的情况：原图是带标准误差棒的多系列折线图，复刻图也复现该主类型和变体，即使具体点位、趋势或标签有错，O1 仍可高分。
- O1 降档示例：平滑折线变普通折线、堆叠柱变分组柱，主类型还在但特殊变体降级。
- O2 重点是图表表达的数据是否准确。错误趋势、错误点位、量程改写、坐标轴物理逻辑错误、关键标题/图例/单位缺失都属于 O2。
- O2 可读性只在影响语义元素时扣，如标题、标签、图例、刻度、单位严重不可读。
- O3 才处理空间遮挡、边缘留白、裁剪、整体布局、背景、颜色、字体、线条粗细、点型等视觉风格问题。
- 最常见错误：看到文字遮挡或布局问题就直接在 O1 扣分，这是错误的；遮挡通常归 O3，若导致语义元素不可读，也可能影响 O2。
- O2 和 O3 有边界交叉时，优先看问题本质：若影响数据/标签/图例/刻度的表达准确性，归 O2；若主要是空间关系、遮挡、留白、风格一致性，归 O3。

## 分数与理由要求

- Rubric 分数：每条 rubric 对 image1/image2 分别打 1、0.5、0。
- Rubric 理由可较简短，但必须说出具体可见差异，不要只写“准确”“不准确”。
- 维度分理由必须更详细，尤其是给 1、2、3 这类非满分/非零分时，要解释为什么是这个档位。
- 录屏强调本批会根据 image1/image2 的 O1/O2/O3 六个维度分一致性判断是否进入质检，因此维度分和理由要认真。
- AHT 参考：认真做单题通常约 20 分钟，复杂题可接近 27 分钟；过快且质量差会被关注。

## 废弃与质检

- 当前标注环节没有废弃按钮，录屏明确说“不允许废弃”“现在所有题目只能做”。
- 质检队列会单独建立，普通标注阶段不用处理质检逻辑。
- AB 双盲标注后，若两位标注同学的 O1/O2/O3 维度分不一致，后续会进入质检队列。
- 质检不是返修，质检同学最终决定 A 好还是 B 好；质检也会被抽查。

## 理由话术

- 理由要短而具体，直接引用可见事实。
- 点明具体图表组件：图表类型、散点、误差棒、图例、坐标轴、色条、标题、数据源说明、主峰/次峰区域、关键数据点、遮挡位置等。
- 不要泛写“更像原图”“更准确”。要说明准确在哪里或错在哪里。
- 维度理由不要写“rubric 得分较低所以给 2 分”，而要写具体错误，例如“X 轴端点被改写，导致趋势位置判断不准确，因此 O2 给 2 分”。

## 问卷知识点

- 原图是唯一参考基准。
- O1 看图表类型、特殊变体和意图，不能混入数据、遮挡和风格问题。
- O2 看数据映射、坐标轴、趋势、静态辅助元素和语义可读性。
- O3 看布局、遮挡、裁剪、留白、颜色、字体、线条和视觉风格。
- Rubrics 必须先检查和优化，不准时要修改或补充。
- 每条 rubric 对 image1/image2 都要单独打分并写理由。
- O1/O2/O3 维度分不同于 rubric 分，维度理由要详细。
- Overall 公式：O1=0 时 overall=0；O1>=2 时 overall=0.25*O1+0.65*O2+0.10*O3。
- O1=0 后仍然要继续完成后续分数和理由。
- Pairwise 不是纯主观美观判断，也不是机械只看某一个小细节；高优先级是图表类型和数据准确性。
