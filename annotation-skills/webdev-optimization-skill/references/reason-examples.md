# Reason Examples

Use these as phrase pools, not fixed templates.

- 功能完整度满足核心需求，页面整体可用，但部分细节还可以优化
- 功能完整度未覆盖 prompt 中的主题切换要求，需要补充对应交互
- 按钮点击后没有明显反馈，关键操作链路不可用
- 页面白屏，控制台报错，当前无法正常判断核心功能
- 页面处于 ready to build 状态，当前产物未能正常完成渲染
- 图片资源加载失败，内容展示不完整
- 游戏核心玩法可以操作，整体逻辑自洽，但场景特色元素还可以补充
- 游戏控制响应异常，当前基本无法正常游玩
- 动画可以正常播放，但交互反馈较弱，当前体验还有提升空间
- 场景缺少动态效果，不符合动画场景要求
- 移动端视窗下布局出现遮挡，需要优化适配
- 整体观感中规中矩，基础布局可用，但局部边距和对齐仍需优化
