# Learned Patterns

Add reusable user corrections here.

Format:

- Pattern: <task or situation>
  Pass/choose condition: <what is enough>
  Fail/waste condition: <what is not enough>
  Reason style: <preferred wording>

- Pattern: Pairwise webpage or sketch replica judgement
  Pass/choose condition: Higher-priority dimensions decide first, especially layout, position, size, spacing, first-screen content, module order, and core content
  Fail/waste condition: Do not flatten to Same just because the other side has better color, image mood, or minor detail when the higher-priority gap is clear
  Reason style: Use comma-only oral Chinese, mention the higher-priority winning point first

- Pattern: Broken image in a visible key area
  Pass/choose condition: Choose the other candidate when it is otherwise judgeable and does not have the same key broken-image issue
  Fail/waste condition: Broken hero images, product images, doctor photos, chart images, avatars, or main card images are significant completeness and restoration defects
  Reason style: Use comma-only oral Chinese, say the key image did not load and the page completeness is worse

- Pattern: Avoid over-focusing on the latest correction
  Pass/choose condition: Treat new user corrections as guardrails inside the complete rubric, then still check all applicable dimensions for the item
  Fail/waste condition: Do not judge only from the most recently discussed rule while ignoring layout, completeness, content, visual restoration, hallucination, explicit functions, or broken rendering
  Reason style: Use comma-only oral Chinese, mention the highest-priority decisive evidence first
