## Likely Quiz Facts

- GSB labels are `A good B`, `A bad B`, and `A same B`.
- Explicit prompt function requirements must be tested; no explicit function means judge visual/restoration or flow realization only.
- Sketch tasks prioritize layout, content filling, productized completion, prompt style, then explicit functions.
- Webpage replica tasks prioritize reference fidelity over independent beauty.
- Flowchart tasks prioritize flow semantics and real webpage/product implementation over redrawing nodes and arrows.
- Flowchart tasks may mock backend/API/login/payment/notification behavior if request, response, loading, success, and error states are reasonably shown.
- Extra unrequested functionality does not add points and can be negative if it breaks restoration or relevance.
- Reasons must cite concrete evidence, not just say "overall better".
