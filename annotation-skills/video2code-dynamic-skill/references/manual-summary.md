# Video2code 标注手册摘要

## 字段

- 输入字段：`video`、原始 HTML/GT HTML、`rubrics`。
- 模型输出：5 个 HTML 代码及对应链接。

## 人标逻辑

- 分静态和动态两个维度。
- 静态维度参考 RFT bon7 标注文档。
- 动态维度需要根据视频和原始/GT HTML，对生成 HTML 产物按每条 rubric 打分，再给整体动态分。

## Rubric 校对

- 每条 rubric 都要先审查合理性。
- rubric 中的精确时间、间距、秒数等不必严格按字面执行，应结合视频呈现修正成合理描述。
- rubric 与视频/网页完全不一致时标为错误并剔除。
- 如果 rubric 所指内容重要，但描述不合理，先 fix 再保留。
- 每条 rubric 需要判断核心/非核心。核心性按视觉观感、占比和变化明显程度判断。

## 静态评分

- 静态按 0/1/2/3。多个 2 分时，最优者可晋升为 3 分。
- 静态不通过的 rollout 直接淘汰。
- 静态页面核心内容缺失直接废弃。
- 静态分值为 1、2 且“非还原，可利用”为 1、2 时需要录制视频，录制内容要覆盖 rubric 为 1 分的对应内容。

## 动态评分

- 单条 rubric 分数为 0/1：
  - 0：不符合。
  - 1：符合。
- 单条 rubric 还需记录：
  - 是否修正 `is_fixed`。
  - 修正后的 `fixed_rubric_text`。
  - 是否丢弃 `should_drop`。
  - 是否核心 `is_core`。
- 整体动态分为 0/1/2：
  - 0：整体不符合要求。
  - 1：整体符合全部要求。
  - 2：多个 1 中最好的一个；每个 sample 最多一个 2。

## 推荐流程

1. 看视频和 GT HTML。
2. 校对 rubrics。
3. 对每个 rollout 做静态评分。
4. 对静态通过的 rollout 按 rubric 做动态评分。
5. 给 rollout 整体动态分。
6. 写入标注人、标注时间和 notes。

## 关键提醒

- 以视频和 GT HTML 为准，不要机械执行过细的 rubric 文案。
- 静态核心内容缺失或页面不可用时优先废弃/淘汰。
- 动态整体分要综合核心 rubric 权重，不能简单平均。
- 理由要短、准、自然，重点说明影响分数的核心差异。
