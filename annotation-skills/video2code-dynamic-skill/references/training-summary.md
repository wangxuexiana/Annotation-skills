- 正确视频妙记：https://bytedance.larkoffice.com/minutes/obcnu94h2681gp9i5g45ko6n

- 目标：根据视频和原始/GT 页面理解参考效果，校对并必要时拆分/合并 rubrics，再对 5 个网页产物分别评静态还原和动态还原。

## 废弃的错误材料

- 之前误读的视频 `obcnu287bldcgc15397199a3` 不是本队列培训视频。
- 该错误视频中的 O1/O2/O3 图表复刻静态维度边界不作为 Video2code 有效规则，不应用于本队列问卷或标注。

## 核心判定

- 本队列仍是 rubric 评分，但需要先根据视频和原始/GT 页面自行校对、拆分或合并 rubric。
- 评分分两部分：静态页面还原度、动效还原度。
- 静态页面按 BON7/RFT 既有标准评 0/1/2/3：
  - 0/1/2 正常评。
  - 多个 2 分时，选择最好的一个晋升为 3；只有一个 2 分时一般不必晋升。
- 静态分为 0 的单个产物直接跳过，不继续评它的动态；其他产物正常评。
- 如果整个 sample 的所有产物都严重缺失核心内容，可整题废弃；如果只是单个产物核心功能缺失，则该产物静态给 0，其他产物继续正常评。
- 动态单条 rubric 打 0/1：
  - `0`：不符合该 rubric。
  - `1`：完全符合该 rubric。
- 动态整体分打 0/1/2：
  - `0`：整体不符合要求。
  - `1`：全部/核心动态要求符合。
  - `2`：多个 1 分产物中表现最好的一个晋升为 2。

## Rubric 校对与修正

- 自动拆出的 rubric 需要人工核对，不能机械照单全收。
- 过细的时间、间距、秒数不用严格执行，例如“4 秒”“播放约 2 秒”“加载 1.2 秒”应改成更模糊合理的描述，如“需要播放”“需要加载”。
- 如果 rubric 与视频和网页呈现完全不一致，判断该 rubric 是否错误：
  - 不涉及核心功能的错误 rubric 可以剔除。
  - 涉及核心功能的 rubric 不要直接删除，应自行修正后保留。
- 每条 rubric 需要标注是否核心。核心判断以视频中的视觉/操作重要性为准：
  - 视频里着重操作的部分、展示时长占比大的部分、对主要动效或交互影响大的部分通常是核心。
- 可以视情况整合同模块、同类目、同功能的 rubric，避免被拆成二三十条后机械标注。
- 不能跨维度或跨模块整合。例如同一个表格里的点击/查看操作可以合并，但不能把上方模块操作和下方模块操作合成一条。

## 标注流程

1. 先看原视频和原始/GT 页面，理解页面应有的静态布局、内容和动态操作。
2. 校对自动拆分的 rubrics：修正、剔除、合并或保留，并标注核心/非核心。
3. 对每个产物先评静态还原度。
4. 静态为 0 的产物跳过动态；静态为 1/2/3 的产物继续评动态。
5. 对每个保留的动态 rubric 分别给 0/1，并写清给分原因。
6. 给每个产物整体动态分 0/1/2，并写整体原因。
7. 写入备注、标注人和标注时间。

## 操作页面细节

- rubric 的原文修改、是否核心、增删 rubric 标签会在 5 个页面/产物之间联动同步。
- 单个产物的分值和原因不会联动，因为每个产物表现不同，需要分别填写。
- 产物链接在当前对应标签页中，可打开新窗口查看；视频也可在新页面看完整版本，不要只依赖小窗口。

## 录屏要求

- 静态分为 1/2 且“非还原，可利用”为 1/2 时，需要录制新视频。
- 录屏需要包含当前页面产物中所有动态 rubric 得 1 分的相关内容。
- 动态 rubric 为 0 的内容可以不录。
- 录屏是录当前产物页面，不是录原始视频。

## 易错点

- 不要严格卡 rubric 里的具体秒数、间距，要按视频呈现合理泛化。
- 不要把核心 rubric 直接删掉；核心点描述不合理时应修正后保留。
- 静态为 0 的产物不继续评动态。
- 核心内容缺失要区分整题缺失和单产物缺失：整题严重缺失可废弃，单产物缺失则该产物静态 0。
- 视频布局和实际产物布局顺序不一致时，要结合实际实现效果判断。实现效果不错时可给静态 1 并正常标注，不要直接给 0 或废弃。
- 动态整体 2 不是“全部符合”，而是多个整体 1 分中的最佳晋升。
- rubric 合并必须同模块、同类目、同功能，不能跨模块或跨维度。

## 理由话术

- rubric 和整体评分都必须写原因。
- 原因要说明具体给分依据，短但准确。
- 修正 rubric 时说明“原描述过细，按视频泛化为……”“原 rubric 与视频不一致，非核心剔除”“核心功能保留并修正为……”。
- 动态整体原因要体现核心 rubric 完成情况，以及为什么某个 1 分产物可晋升为 2。

## 问卷知识点

- 单条动态 rubric 分值是 0/1。
- 动态整体分值是 0/1/2；2 是多个 1 中表现最好的一个。
- 静态评分为 0 的产物直接跳过，不做动态评分。
- 静态页面参考 BON7/RFT 标准。
- 过细秒数和间距不严格遵守，应按视频合理泛化。
- 核心 rubric 按视频里操作/展示的重要性判断。
- 核心功能相关的错误 rubric 要修正保留，非核心且错误的 rubric 可剔除。
- 同模块同功能 rubric 可以合并，跨模块/跨维度不能合并。
