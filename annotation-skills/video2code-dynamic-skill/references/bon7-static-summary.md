# BON7 静态产物评分手册摘要

来源：https://bytedance.larkoffice.com/wiki/Mo1hwplASi3vR5khYarcn0Uen8b

## 标注目标

- 静态维度按 RFT bon7 手册判断：对比参考截图和模型生成产物的视觉还原度。
- 核心原则：只看产物对截图的还原度，不看功能和交互。
- 如果参考截图本身存在裂图或空白图片，而产物排版正常并填充了图片，产物可视为更优。

## BON7 原始分值

- 2：页面整体布局、结构、主要元素、视觉层级与参考图高度一致；关键模块都在，位置关系合理。
- 1：整体框架基本对，但存在样式、布局、细节偏差。
- 0：与参考图差异很大，主体结构错误或关键内容缺失。

## Video2code 静态分适配

- Video2code 静态维度沿用 BON7 判断标准，但分值为 0/1/2/3。
- 多个 rollout 达到 BON7 2 分水平时，从中选出最优者晋升为 3。
- 只有一个 rollout 达到 2 分时，不需要强行晋升为 3。
- 静态评分不通过的 rollout 直接淘汰，不再继续动态评分。

## 勾选与原因

- BON7 中 0 / 1 分必须勾选“视觉不足”。
- 所有正常静态分都需要填写评分原因。
- 静态原因重点写布局、结构、主要元素、视觉层级、色块、尺寸、位置关系等可见差异。

## 图片规则

- 参考网页图片内容与实际渲染图片内容不一致时可以忽略，包括随机图、占位图等，只要图片不是裂开的即可。
- 裂图、坏图不能豁免，存在关键裂图时不能给到 2。
- 不能只因图片主题、人物、风景或素材内容不同而降低静态分；应看图片区域是否存在、尺寸位置是否合理、是否正常渲染。
