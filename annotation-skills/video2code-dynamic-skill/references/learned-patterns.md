# Learned Patterns

Add reusable user corrections here.

Format:

- Pattern: <task or situation>
  Pass/choose condition: <what is enough>
  Fail/waste condition: <what is not enough>
  Reason style: <preferred wording>

- Pattern: Video2code 静态还原度出现多个 2 分候选页
  Pass/choose condition: 在所有静态 2 分候选中选择视觉与参考视频最接近、结构和内容节奏最完整的一页，将其静态还原度晋升为 3；只有一个 2 分时不强行给 3
  Fail/waste condition: 多个页面都保持 2 分而没有挑选最佳页升 3，属于漏用 BON7 静态评分规则
  Reason style: 备注里简短说明该页“静态布局和视觉质感最接近参考”或“整体视觉最接近视频”
