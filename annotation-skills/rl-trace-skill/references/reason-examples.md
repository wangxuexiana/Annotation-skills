# Reason Examples

Short natural Chinese examples for RL Trace. Use these as phrase pools, not fixed templates.

- UP 无明确功能要求，function 不参与整体 GSB。
- A 视觉更接近参考图，但 B 完成核心筛选交互，整体判 B 更好。
- 两者都保留大量 Placeholder，视觉 same。
- 参考图为草图，按草图任务评价，A 产品化更完整。
- 复刻任务看接近参考图，A 的布局和元素完整性更好。
- 仅视觉不看功能，A/B 视觉差距不明显。
- prompt 要求正常运行，A 点击后无状态变化，整体不如 B。
- 截图或 HTML 打不开，关键材料缺失，按废弃处理。
- A 新增了参考图没有的大模块，复刻准确性更差。
- B 虽然局部更美观，但 A 的结构和首屏内容更贴近参考图。
